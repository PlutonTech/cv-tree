    Not imported

    LinkedIn doesn't share your experience with other apps, so CV Tree reads it from your profile page instead.

    1. Click Connect LinkedIn. Your profile opens in a new tab.
    2. Click the CV Tree button in the corner of that page, then Import this profile.
    3. For every role, open “Show all experiences” on LinkedIn and import that page too.

    Settings

    Everything is stored in this browser only. Your API key is only sent to the AI provider you pick.

    AI provider

    No key needed. CV Tree's free AI runs on Claude with a daily allowance per person. For unlimited use, choose My OpenRouter key and add a free key.

    Claude models need OpenRouter credits and a normal API key (not a management key). Free models have a daily request limit. If you get a privacy error, allow free model providers at openrouter.ai/settings/privacy.

    Widget

    You can always open it from the CV Tree icon in the browser toolbar, on any page.

    Read the privacy policy

    Helps improve CV Tree. Sent: which features you use, AI model names, response times and error codes, job-site domains (like linkedin.com) and template names, under a random install ID.
    Never sent: your CVs, cover letters, name, contact details, profile, job descriptions or API keys.
